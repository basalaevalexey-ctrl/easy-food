# MVP Telegram-бота "AI счетчик калорий"

Дружелюбный Telegram-бот на Python 3.11, aiogram 3, SQLite и OpenAI API.

Бот принимает текст или фото еды, примерно считает калории и БЖУ, сохраняет запись в дневник и показывает прогресс за день.

## Возможности

- `/start` - приветствие и меню.
- `/setup` или кнопка "Настроить цель" - пошаговая настройка профиля.
- Текстовое добавление еды: `2 яйца, творог 200 г, банан`.
- Фото еды с примерной оценкой через OpenAI Vision.
- Корректировка записи: порция меньше, порция больше, указать граммы, удалить.
- `/today` или "Сегодня" - прогресс за текущий день.
- `/history` или "Дневник" - последние 7 дней.
- `/help` или "Помощь" - короткая справка.
- `/stats` - статистика только для админов из `ADMIN_IDS`.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка

Скопируйте `.env.example` в `.env` и заполните значения:

```env
BOT_TOKEN=123456:telegram_bot_token
OPENAI_API_KEY=sk-...
ADMIN_IDS=123456789,987654321
OPENAI_MODEL=gpt-4o-mini
```

`ADMIN_IDS` можно оставить пустым, если команда `/stats` не нужна.

## Запуск

```bash
python -m app.bot
```

При первом запуске рядом с проектом создастся файл `calories.sqlite3`.

## База данных

SQLite создает две таблицы:

- `users` - профиль, цель, дневная норма калорий и белка.
- `food_entries` - записи еды с калориями, БЖУ, источником и временем.

## Примечания

Оценки еды примерные, особенно по фото. Бот не является медицинской рекомендацией и не заменяет врача.
